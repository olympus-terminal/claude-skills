# Publication-Ready Repository Audit

Prepare a scientific repository to accompany a peer-reviewed manuscript. The repository will be scrutinized by reviewers, editors, and readers. It must look like a finished, professional product — not a workspace.

## Setup

1. Identify all repositories (GitHub, HuggingFace, Zenodo, Figshare, Dryad). Get URLs or local paths.
2. Identify the manuscript citation (authors, title, journal). This replaces vague references like "the accompanying manuscript."
3. Clone or locate each repository locally. For HuggingFace, use `GIT_LFS_SKIP_SMUDGE=1` to avoid downloading large files.

## Audit Passes

Execute four passes across ALL repositories. Each pass produces a findings list before any edits.

### Pass 1: Work-in-Progress Language

Scan every text file (README, docs, comments, model cards, YAML frontmatter, docstrings) for:

- Placeholder references: "the accompanying manuscript," "manuscript in preparation," "paper in prep," "forthcoming"
- Co-author coordination: "please add," "co-authors should," "contributors please," "when adding files"
- Hedging qualifiers: "(if needed)," "(TBD)," "(placeholder)," "(draft)," "(WIP)," "(temporary)"
- Placeholder figure/table numbers: "Figure X," "Table S?," "Supplementary ??"
- TODO/FIXME/HACK comments in any source file
- Internal notes not meant for public consumption

For each finding: note file, line number, offending text, and what it should become.

### Pass 2: AI Provenance Scrub

Reviewers and editors actively look for AI fingerprints. Scan for:

- Commit messages: `Co-Authored-By` trailers referencing Claude, GPT, Copilot, or any AI tool. Also check for `noreply@anthropic.com`, `noreply@openai.com`.
- Commit author/committer metadata: any non-human team member.
- Contributors page: GitHub derives contributors from commit metadata — even deleted trailers persist if old refs remain. After rewriting, purge `refs/original/`, expire reflogs, and `gc --prune=now`.
- File contents: comments like "generated by Claude," "AI-assisted," etc.
- Git blame: no commit should have a non-human author/committer.
- Hidden files: `.claude/`, `.copilot/`, `.cursor/`, `.aider/`, or any AI tool configuration accidentally committed.

Complete remediation for commit history:
```bash
git filter-branch -f --msg-filter 'sed "/Co-Authored-By:.*[pattern]/d"' -- --all
git update-ref -d refs/original/refs/heads/main
git update-ref -d refs/original/refs/remotes/origin/main
git reflog expire --expire=now --all
git gc --prune=now --aggressive
git push --force origin main
```
After force push, verify via `gh api repos/OWNER/REPO/contributors --jq '.[].login'` that only human accounts appear.

### Pass 3: Structural & Metadata Completeness

- README: present, substantive, includes title, description tied to citation, repo structure, reproduction instructions, dependencies, citation block, license
- LICENSE file: present and appropriate
- Citation block: every README must contain the manuscript reference
- Data provenance: documentation of how outputs were generated
- requirements.txt / environment.yml: dependencies pinned or version-bounded
- HuggingFace model cards: proper YAML frontmatter (language, license, tags, pipeline_tag)
- Zenodo metadata: `.zenodo.json` with creators, title, description, keywords
- Cross-references: GitHub and HuggingFace link to each other; Zenodo DOI badges present
- No empty directories, `.gitkeep` files in directories with content, or empty stubs

### Pass 4: Code Hygiene

- Hardcoded paths: `/home/username/`, `/scratch/`, `/Users/`, HPC-specific paths — all should be relative
- Dead imports: modules imported but never used
- Commented-out code blocks: 20+ lines of dead code is not acceptable
- Debug prints: `print()` for debugging should be removed or replaced with logging
- Credentials or secrets: API keys, tokens, passwords, `.env` files

## Final Verification Checklist

After all changes, verify:

```
[ ] Every README references the manuscript by citation, not by vague pointer
[ ] No TODO/FIXME/HACK/WIP/TBD in any committed file
[ ] No AI tool references in commit history (messages, author, committer)
[ ] Contributors list shows only human team members
[ ] No hardcoded local/HPC paths in any script
[ ] License file present in every repository
[ ] Citation section present in every README/model card
[ ] Cross-links between companion repositories are correct
[ ] Reproduction instructions reference actual existing files
[ ] No credentials, secrets, or .env files committed
[ ] No AI tool configuration directories committed
[ ] HuggingFace model card YAML frontmatter is complete
```

Report each item as PASS or FAIL with a note. Any FAIL must be resolved.
